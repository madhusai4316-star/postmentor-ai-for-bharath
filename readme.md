# 🚀 CreatorPilot – AI-Powered Instagram Growth Manager

CreatorPilot is an AI-powered content strategy and growth intelligence platform built to help beginner Instagram creators plan, create, and improve their content with clarity and confidence.

It acts as a personal AI content manager — not just a caption generator.

---

## 📌 Problem

Beginner Instagram creators often struggle with:

- Not knowing what to post  
- Posting inconsistently  
- Weak hooks and low engagement  
- Poor understanding of analytics  
- Lack of actionable feedback  

Most existing tools generate captions but fail to provide strategic growth guidance.

---

## 💡 Solution

CreatorPilot transforms user inputs (niche, time availability, content style, and performance metrics) into structured, AI-powered growth insights.

The platform:

- Generates optimized Reel ideas and scripts  
- Recommends best posting times  
- Analyzes post performance  
- Detects mistakes  
- Provides improvement strategies  
- Delivers weekly AI coaching reports  

---

## ✨ Key Features

- 🔍 Personalized onboarding (niche, goals, time commitment)  
- 🎬 AI-generated Reel topics, hooks, scripts, captions, and hashtags  
- ⏰ Smart posting-time recommendations  
- 📊 Performance analysis engine  
- 🧠 Mistake detection & improvement guidance  
- 📈 Weekly AI growth reports  
- 🔐 Secure authentication & subscription management  

---

## 🏗️ Tech Stack

- **Frontend & Backend:** Next.js  
- **Styling:** Tailwind CSS  
- **AI Engine:** OpenAI API  
- **Database:** Supabase (PostgreSQL)  
- **Authentication:** Clerk  
- **Payments:** Stripe  
- **Hosting:** Vercel  

---

## 🧠 How It Works

1. User completes onboarding (niche, time availability, goals).
2. AI generates personalized content strategy.
3. User creates and posts content.
4. User inputs performance metrics.
5. AI analyzes performance and provides structured feedback.
6. Weekly report reinforces the growth loop.
